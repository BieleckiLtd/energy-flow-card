Get it for Home Assistant
  1. With HACS: HACS → ⋮ → Custom repositories → add https://github.com/BieleckiLtd/energy-flow-card as Dashboard, then download Energy Flow Card.
  2. Or by hand: download energy-flow-card.js, put it in /config/www/ and add /local/energy-flow-card.js under Settings → Dashboards → ⋮ → Resources as a JavaScript module.
  3. Edit a dashboard → Add card → Energy Flow Card, or paste the YAML below into a Manual card. It carries the names and colours set here; swap in your own sensors.
  4. Weather: the card follows a weather.* entity. Most installs already have weather.forecast_home from Met.no (free, no API key); if not, add the Met.no integration under Settings → Devices & services.
